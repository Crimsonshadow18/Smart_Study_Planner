# Smart Study Planner

A machine learning project that predicts how many hours per day a student should study each subject and builds a weekly timetable.

## Files
| File | Purpose |
|---|---|
| `generate_data.py` | Creates the simulated dataset `data.csv` (6000 rows) |
| `data.csv` | Dataset: subject type, difficulty, confidence, last score, topics remaining, days left, free hours -> recommended hours/day |
| `index.ipynb` | Jupyter notebook: EDA, preprocessing, model training, evaluation, saving the model |
| `model.joblib` | Saved Gradient Boosting model (used by the app) |
| `app.py` | Streamlit web app |
| `requirements.txt` | Libraries needed |

## How to run
1. Install Python 3.9 or newer.
2. Open a terminal in this folder and run:
   ```
   pip install -r requirements.txt
   streamlit run app.py
   ```
3. The app opens in the browser (usually http://localhost:8501).

To re-run the notebook, install Jupyter (`pip install notebook`), run `jupyter notebook` and open `index.ipynb`.
To regenerate the dataset, run `python generate_data.py`, then re-run the notebook to refresh `model.joblib`.

## Note
The dataset is simulated (generated by `generate_data.py` from a workload rule plus random variation). It is not collected from real students.
